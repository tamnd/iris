# irisdb

`iris`, the command line tool.

Inspects, verifies and decodes iris datasets. Nothing is implemented yet.

The package is `irisdb` and the binary is `iris`. crates.io holds `iris` on its reserved name list, so `cargo install irisdb` is how you get a binary called `iris`.

Part of [iris](https://github.com/tamnd/iris). Licensed under Apache-2.0.
